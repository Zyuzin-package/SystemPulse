# SystemPulse — инструкции для агента

## Контекст проекта
- SystemPulse — учебный проект для сбора и обработки ошибок Java-сервисов.
- Если существует docs/design.md, сверяйся с ним. Неопределённые решения не додумывай — спроси, если задача от них зависит.
- Целевой стек по дизайну — Java 21, Spring Boot и PostgreSQL. Перед изменениями проверь pom.xml и текущий код; не меняй настройки сборки и версии зависимостей молча.
- Не добавляй отложенные компоненты — Elasticsearch, Kafka, Telegram, LLM и другие — без прямой задачи.

## Работа над задачами
- Для неоднозначной или нетривиальной задачи сначала изучи относящийся к ней код, предложи короткий план и дождись подтверждения перед изменениями.
- Для небольшой и чётко ограниченной задачи можно сразу переходить к реализации.
- Меняй только то, что относится к задаче; не делай несвязанных рефакторингов.
- При изменении поведения добавляй или обновляй тесты.
- Запускай тесты через Maven Wrapper, если он есть; иначе используй Maven. В отчёте указывай точную команду и результат.
- Не коммить, не отправляй изменения на сервер и не развёртывай приложение без прямой просьбы.

## Объяснения
- Для обычной работы используй доступный в проекте skill Caveman, сохраняя ответы компактными.
- После заметных изменений кратко объясняй, как проходит выполнение по изменённому коду и какой новый принцип здесь используется. Не сокращай объяснение, если пользователь просит разобраться подробнее.
